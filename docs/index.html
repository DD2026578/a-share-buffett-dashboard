05市场确认

成交额代表资金活跃度，涨停/跌停代表情绪。成交额放大、涨停多，通常说明资金在进场。
市场宽度看的是全市场涨跌家数的分布：涨的家数远多于跌的，说明行情是普涨（赚钱效应好）；指数在涨但下跌家数居多，说明只是少数权重股在拉，赚钱效应差。

估值告诉你“贵不贵”，资金与情绪告诉你“撑不撑得住”。

08口径与敏感性

说明数据怎么算、有哪些口径差异，避免把不同市场的数字直接对比。
  • 总市值口径：上证指数 + 深证综指 + 北证50；北交所占比约 0.75%，主读数与历史 880001 口径一致（含北交所）。
  • GDP 口径：主读数用前一年度 GDP（滞后但稳定）；TTM 口径为 141.76 万亿，读数为 --。
  • 阈值：固定阈值来自 2011–2026 均值 ±20%；滚动模式用最近窗口均值 ±1σ，可在上方切换。
  • PE / PB：深证成指、创业板、科创50、沪深300、中证500、中证1000、红利、消费、医药、白酒、银行、证券来自蛋卷指数估值（含历史分位）；上证 PE 取上交所官方平均、PB 按沪市前 300 只市值加权估算；北证50 按市值前 50 估算。无历史分位的指数只显示 PE/PB，不做“贵/便宜”判断。
  • 880001：通达信板块指数，“A股总市值”点位 = 总市值 × 100，1 点≈100 亿元；本页用沪深京总市值 ×100 计算等价值（与通达信真实 880001 月末点位逐月校准），它不是股价指数，反映的是市场规模。
  • 市场宽度：实时涨跌家数取东方财富上证指数 + 深证综指行情的涨/跌/平家数（f104/f105/f106）合计，不含北交所；历史序列由通达信 880001 日线回补（含北交所，平盘未单列）。涨家占比 ≥70% 记为火热、50–70% 偏暖、20–50% 偏冷、<20% 冰点。
  • 局限性：证券化率只反映市值/GDP，不等于盈利估值；A股与美股、港股不可直接横向比较。
